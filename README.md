# Мастерская ПК

Учебный 3D-сайт для студентов колледжа: из чего состоит персональный компьютер и как его собрать.

## Режимы

- **Обучение** — сборка системного блока в корпусе с подсказками: плата, блок питания, процессор, термопаста, кулер, память, SSD, видеокарта, жёсткий диск и 11 кабелей — питание от блока питания, вентиляторы (CPU_FAN, SYS_FAN) и разъёмы корпуса (F_PANEL, USB 3.0, USB-C, HD Audio). Кабели проложены за поддоном и выходят через резиновые люверсы. Сайт объясняет ошибки и проверяет сборку самотестом POST по индикаторам Q-LED: например, без F_PANEL кнопка на корпусе не включит компьютер, а без кабеля вентилятора кулера загрузка остановится с ошибкой CPU Fan Error. После самотеста монитор показывает экран BIOS: процессор и его температуру, память и режим каналов, накопители, видеокарту и обороты вентиляторов.
- **Рабочее место** — собранный компьютер на столе: ставим монитор, клавиатуру, мышь, колонки и подключаем кабели (HDMI, USB, аудио, Ethernet, питание через сетевой фильтр). Включение показывает типичные ошибки — например, «Нет сигнала», если монитор подключён к материнской плате, а не к видеокарте.
- **Тест** — два задания без подсказок. «Сборка с нуля»: собрать системный блок полностью. «Найди неисправность»: в собранном компьютере спрятаны три неисправности (не подключён кабель, нет термопасты, память в одном канале и т. п.) — их нужно найти по индикаторам Q-LED, экрану BIOS и виду корпуса и исправить. Считаются ошибки, время и лишние включения, в конце выставляется оценка; результат можно скопировать и отправить преподавателю.
- **Энциклопедия** — каждая деталь крупно в 3D: её можно вращать и разобрать на слои, у каждой части есть подпись и описание, а также советы по выбору.

## Запуск

Откройте `index.html` в браузере (Chrome, Edge или Firefox). Нужен интернет: библиотека Three.js и шрифты загружаются из CDN.

## Технологии

- [Three.js](https://threejs.org/) 0.160 — 3D-сцена
- Все комплектующие построены в коде, без брендов. Корпус — реалистичная модель из папки `models/` (`.glb`, а для запуска с диска — копия в `.js`); если файл не загрузится, остаётся корпус из кода.

Изменено: убраны подставка, отвёртка и боковое стекло, модель переведена в сантиметры и уложена на бок, нижний отсек сделан выше под стандартный блок питания ATX, сетка верхнего фильтра заменена текстурой.
