# Мастерская ПК

Учебный 3D-сайт для студентов колледжа: из чего состоит персональный компьютер и как его собрать.

## Режимы

- **Обучение** — сборка системного блока в корпусе с подсказками: плата, блок питания, процессор, кулер, память, SSD, видеокарта, жёсткий диск и пять кабелей. Сайт объясняет ошибки и проверяет сборку самотестом POST по индикаторам Q-LED.
- **Тест** — та же сборка без подсказок. Считаются ошибки и время, в конце выставляется оценка; результат можно скопировать и отправить преподавателю.
- **Энциклопедия** — каждая деталь крупно в 3D: её можно вращать и разобрать на слои, у каждой части есть подпись и описание, а также советы по выбору.

## Запуск

Откройте `index.html` в браузере (Chrome, Edge или Firefox). Нужен интернет: библиотека Three.js и шрифты загружаются из CDN.

## Технологии

- [Three.js](https://threejs.org/) 0.160 — 3D-сцена
- Все модели деталей построены в коде, без внешних файлов
