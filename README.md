# Мастерская ПК

Учебный 3D-конструктор для студентов колледжа: из чего состоит персональный компьютер и как его собрать.

Студент перетаскивает комплектующие на материнскую плату: процессор, кулер, оперативную память, видеокарту. Сайт подсвечивает нужный слот, объясняет ошибки и проверяет сборку при включении по индикаторам Q-LED.

## Запуск

Откройте `index.html` в браузере (Chrome, Edge или Firefox). Нужен интернет: библиотека Three.js и шрифты загружаются из CDN.

## Технологии

- [Three.js](https://threejs.org/) 0.160 — 3D-сцена
- Модели деталей построены в коде, без внешних файлов
